## Contexte

OpenClaw est un agent IA open-source qui tourne sur ta propre machine (ou VPS).  
- 247 000+ ⭐ GitHub en 60 jours — viral en ce moment  
- Fonctionne via WhatsApp, Telegram, Discord, Slack, Signal, iMessage  
- Automatise : inbox, emails, calendrier, fichiers, navigation web  
- Données restées sur ta machine (privacy-first)  
- Gratuit — nécessite un accès à un modèle IA (Claude, GPT, ou local)

**Différenciateurs :**
- Open source + auto-améliorable (peut créer ses propres extensions)
- Mémoire persistante 24/7
- Accès système complet (fichiers, shell, navigateur)

**Limites identifiées :**
- Pas plug-and-play : nécessite Node >= 22 + WSL2 (Windows)
- Setup technique — accessible à un fondateur solo ?
- Si l'IA mal comprend une instruction, elle peut quand même l'exécuter
