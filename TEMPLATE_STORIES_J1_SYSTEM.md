# SYSTEM — Stories J1 (Test Day Observations)

**Purpose:** Créer un momentum le jour du test (J1) avant la publication du carrousel (J2)  
**Format:** 2 stories séparées (09h + 18h) + screenshots  
**Durée:** 5 min de création (texte court, pas de design complexe)

---

## FRAMEWORK — Pourquoi ce pattern marche

### Story #1 (Matin) — "Shock Setup"
- **Objective:** Montrer le contraste promesse ≠ réalité
- **Tension:** Chiffre (1h vs "quelques minutes")
- **Visual:** Preuve du setup (org chart, interface)
- **Subtext:** Ce truc est plus complex qu'annoncé

### Story #2 (Soir) — "Problem Discovered"
- **Objective:** Montrer une friction réelle ET maintenir curiosity
- **Tension:** Question rhétorique ("Zero-human company ?")
- **Visual:** Preuve du problème (screenshot avec "blocked" visible)
- **Subtext:** Il y a quelque chose à découvrir (jeudi = carrousel)

### CTA Implicite
- Story #1 → fait swiper vers #2 (continuité narrative)
- Story #2 → fait attendre jeudi (carrousel promis = réponse)

## MISE EN PAGE — Spécifications visuelles

### Spécifications texte (Instagram Stories)

| Élément | Specs |
|---------|-------|
| **Résolution** | 1080×1920px (verticale) |
| **Zone texte** | Top 30% + Bottom 30% (screens safe area) |
| **Police** | Inter Bold ou Montserrat (sans-serif) |
| **Taille min** | 40pt pour mobile |
| **Couleur texte** | Blanc (#FFFFFF) |
| **Fond texte** | Dark overlay si screenshot (opacité 40%) |
| **Align** | Centré ou left-align (lisible) |

### Palette couleur

```
Fond: #000000 (noir pur) ou screenshot flouté
Texte principal: #FFFFFF (blanc)
Highlight/chiffres: #00AAFF (cyan brief.ia)
Secondaire: #888888 (gris pour détails)
Accent: #FF6B6B (rouge si critique)
```

## PRINCIPES — Pourquoi ce système marche

### 1. **Contexte progressif**
- J0 (lundi): "Je teste Paperclip" → établit l'outil
- J1 (mardi): Observations spécifiques → maintient l'intérêt
- J2 (jeudi): Carrousel complet → payoff + verdict

### 2. **Pattern A/B (Story #1)**
- Crée un contraste visuel/textuel
- Facile à retenir (promesse vs réalité)
- Chiffres = preuve (pas de bullshit)

### 3. **Curiosity gap (Story #2)**
- Question rhétorique = hook
- Les gens reviennent jeudi pour la réponse
- Plus fort que "Swipe pour plus"

### 4. **Screenshots = crédibilité**
- Rien de faux
- Rien de générique
- Rien qui buzzword
- Juste la réalité capturée

### 5. **Timing narratif**
- Story #1 (09h) = setup, les gens lisent pendant le café
- Story #2 (18h) = soir, curiosity = ils reviennent à jeudi
- Espacement = différentes audiences voient ça 2 fois
