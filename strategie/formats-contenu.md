# Formats de contenu brief.ia

## Vue d'ensemble

| Format | Fréquence | Job | Résultat attendu |
|--------|-----------|-----|------------------|
| TEST & VERDICT carrousel | 2x/semaine | Autorité | Sauvegardes + DMs |
| TEST & VERDICT reel | 2x/semaine | Autorité | Sauvegardes + DMs |
| NEWS + VERDICT reel | 1–2x/semaine | Reach | Partages + nouveaux abonnés |
| Stories | Quotidien | Présence algo | Portée maintenue 7j/7 |

---

## Format 1 — TEST & VERDICT carrousel (7 slides)

Publier : mardi ou jeudi, 7h–9h
Production : 60–75 min (test déjà fait)

```
Slide 1 — HOOK (seul sur fond noir)
Formule : [échec chiffré] + [twist]
Ex : "J'ai passé 2h à configurer 4 agents IA.
Ils m'ont sorti une newsletter sur un outil de 2022."

Slide 2 — CONTEXTE (30 mots max)
Ce que tu voulais faire. Ce que l'outil promet.
Spoiler en gris italique.

Slide 3 — CE QUE J'AI TESTÉ
Conditions exactes. Durée. Cas d'usage réel. Chiffres concrets.

Slide 4 — CE QUI A MARCHÉ
1–2 points positifs vrais. Pas de complaisance.

Slide 5 — CE QUI A MERDÉ
La partie que les autres ne montrent pas.
C'est ici que tu crées la confiance.

Slide 6 — LE VERDICT (fond coloré, texte grand)
Score ou recommandation tranchée. Pas "ça dépend".
Ex : "3/5 — Utile pour du volume, inutile pour de la qualité."

Slide 7 — CTA
"Commente RAPPORT → je t'envoie le test complet en DM"
```

## Format 2 — TEST & VERDICT reel (30–35 sec)

Publier : 2 jours après le carrousel
Production : 30–45 min sur CapCut (template réutilisable)

Vidéo verticale 9:16. Texte animé sur fond noir. Pas de visage. Pas de voix.
Phrases qui apparaissent une par une. Musique courte en fond.

```
[0–3s]   Hook — fait improbable
[3–6s]   Ce que l'outil promet
[6–10s]  "Voilà ce qui se passe vraiment."
[10–15s] Point négatif principal
[15–18s] "C'est du marketing." (3 sec seul — pause forte)
[18–23s] Point positif honnête
[23–28s] "Verdict : X/5"
[28–35s] "Commente RAPPORT → test complet en DM"
```

## Format 3 — NEWS + VERDICT reel (15–20 sec)

Publier : mercredi ou jeudi, 18h
Production : 15–20 min
Source : newsletters lues le lundi matin

Même format technique que le reel TEST & VERDICT mais plus court.

```
[0–3s]   FAIT — l'actu brute
[3–8s]   IMPLICATION — pourquoi c'est important
[8–13s]  VERDICT brief.ia — ce que ça change pour toi concrètement
[13–18s] CTA ou question ouverte
         → "Commente le nom de l'outil — je le teste."
         → ou question : "Quel outil tu attends encore d'intégrer ?"
```

Règle absolue : toujours finir par "et voilà ce que ça change pour toi"

## Format 4 — Stories quotidiennes (5 min/jour)

```
Lundi    — "Je teste [outil] cette semaine." + sondage "tu connais ?"
Mardi    — Teaser carrousel publié le matin (1 slide en story)
Mercredi — Coulisses test en cours (screenshot d'écran + commentaire)
Jeudi    — Question communauté : "Quel outil vous fait perdre du temps ?"
Vendredi — Résultat sondage lundi + teaser reel
Samedi   — Reshare commentaire ou DM intéressant (preuve sociale)
Dimanche — Off ou "je lis [newsletter] ce matin — signal ou bruit ?"
```

## Semaine type

```
Lundi    20 min  Veille + choix actu + choix outil
                 Story "je teste X cette semaine"
Mardi    90 min  Test outil + carrousel → publier 7h
                 Story teaser
Mercredi 20 min  Reel NEWS + VERDICT → publier 18h
                 Story coulisses
Jeudi    45 min  Reel TEST & VERDICT (texte animé)
                 Story question communauté
Vendredi  —      Publier reel test 7h
                 Story verdict + teaser
Samedi   45 min  2e carrousel ou reel news si matière
                 Programmer semaine suivante
Dimanche  —      0 production. Story optionnelle.

TOTAL : ~4h35/semaine
```

## La formule hook (thewizeai adaptée en FR)

```
[Fait improbable ou inattendu sur un outil].
Et ça révèle [implication surprenante pour le business].
```

Exemples :
- "J'ai passé 2h à configurer 4 agents IA. Ils m'ont sorti une newsletter sur un outil de 2022."
- "Cet outil promet l'entreprise sans humains. J'ai trouvé exactement où j'étais encore dans la boucle."
- "Ce SaaS à 49€/mois fait exactement ce que ChatGPT fait gratuitement. Voilà pourquoi certains le paient quand même."
