# Stratégie de capitalisation — @brief.ia

## Séquence de croissance

```
M1–M3  → Instagram (identité + audience qualifiée)
M3–M6  → Newsletter Beehiiv (actif owned, off-algo)
M6–M9  → Sponsoring SaaS + produit digital
M9+    → Extension format long (podcast / YouTube)
```

---

## Extension Podcast — modèle TBPN FR

**Concept :** interviews de fondateurs FR de l'IA avec démos produit en direct — pas du "vision statement"

**Gap existant :** TBPN = insiders US. Le pendant FR n'existe pas encore.

**Acquéreurs potentiels du format :**
- SaaS FR ciblant fondateurs/freelances : Pennylane, Indy, Dougs, Sellsy
- Outils IA FR : Mistral, Dust, Gladia
- Internationaux voulant le marché FR : Notion, HubSpot, Monday.com

**Séquençage d'accès aux fondateurs :**

| Phase | Action |
|---|---|
| M1–M6 | Mentionner / tagger les fondateurs FR dans les tests de leurs outils |
| M3–M6 | Interviews texte en newsletter — barrière d'accès basse |
| M6+ | Format audio/vidéo quand 2–3K abonnés qualifiés comme preuve sociale |

---

## Modèle d'acquisition (type HubSpot / The Hustle)

**La logique :** le coût d'acquisition client via pub explose. Posséder l'audience coûte moins cher que la louer via Meta Ads.

```
Audience qualifiée owned > 10x la même audience en pub payante
```

**Seuils pour devenir acquérable :**

| Signal | Seuil approximatif |
|---|---|
| Newsletter active (taux ouverture >40%) | >3 000 abonnés |
| Audience qualifiée (fondateurs/freelances) | >5K IG ou newsletter |
| Revenus d'affiliation prouvés | >1K€/mois |
| Marque éditoriale distinctive | Dès le début — c'est le plus rare |

**Scénario réaliste à M12–M18 :** partenariat éditorial exclusif avant toute acquisition — indépendance maintenue, financement assuré.

**L'actif non-duplicable :** la ligne éditoriale "verdict tranché + test méthodique" — un acquéreur SaaS ne peut pas la produire sans perdre en crédibilité.

## Segmentation newsletter Beehiiv

**Principe :** à l'inscription, 1 question. La réponse devient un tag sur chaque abonné.

**Formulaire :**
> "Tu es plutôt... ?"
> - Fondateur / CEO
> - Freelance / Consultant
> - Salarié en transition
> - Autre

**Ce que ça débloque :**

- **Court terme :** CTA différenciés selon profil (même contenu, angle adapté)
- **Sponsoring :** un sponsor paie pour un profil d'audience, pas un chiffre brut
- **Acquisition :** "2 000 freelances identifiés, taux ouverture 45%" change la valuation

```
Volume → vanity metric
Volume + segmentation → actif commercial
```

**Règle absolue :** ajouter ce champ dès la création de la page Beehiiv. Impossible à retrofitter proprement sur une liste existante.

## Angles manquants à couvrir

### 1. LinkedIn — l'angle mort majeur
Carousels Instagram = slides LinkedIn. Copier-coller, zéro travail supplémentaire.
L'audience cible (fondateurs, freelances seniors) est massivement plus active sur LinkedIn qu'Instagram.
Ne pas y être dès le départ = ignorer le canal le plus dense en décideurs FR.

### 2. Funnel DM → newsletter
Quand un post performe : répondre aux bons commentaires avec "je t'envoie le lien en DM".
Collecte d'emails manuellement au début — très efficace à 0–500 abonnés.

### 3. UTM tracking dès le premier lien d'affiliation
Sans UTM, impossible de prouver la causalité à un sponsor.

```
?utm_source=briefia&utm_medium=instagram&utm_campaign=nom-outil
```

Structure à appliquer sur tous les liens dès J1.

### 4. Stories — structure hebdomadaire
"Quotidien, 5 min" sans structure ne sert pas l'algo.

| Jour | Format |
|---|---|
| Lundi | Poll : "Quel outil tu veux que je teste ?" |
| Mercredi | Behind the scenes pendant le test |
| Vendredi | Résultat / extrait du post |

Les réponses aux polls = signal algo fort.

### 5. Base de données des outils testés
Un Notion public avec tous les verdicts (outil / use case / verdict / note /10).
Devient un produit en soi à M12. Aussi ce qu'un acquéreur veut voir — la profondeur de couverture.

---

## Points à améliorer dans la stratégie existante

**Ratio verdicts positifs/négatifs :** non défini. Trop de "inutile" → compte qui dit non à tout → fatigue.
Cible : ~50% positif, ~30% mitigé, ~20% négatif tranché.

**"Testable en < 1h" trop restrictif :** certains meilleurs contenus viennent d'un test de 3h.
Reformuler : *"résultat montrable en 1 carrousel"* — c'est la contrainte production, pas le test.

---

## Priorité absolue

Lancer la newsletter Beehiiv **avant** le premier post Instagram.
Chaque post doit avoir un CTA vers elle.
Construire les deux en parallèle dès le départ — pas en séquence.
