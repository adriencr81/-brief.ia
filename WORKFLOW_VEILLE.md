# Workflow de veille IA — @brief.ia

## Comment utiliser Claude dans le workflow éditorial

### Veille & détection du signal
Coller le contenu des newsletters de la semaine (The Rundown, Ben's Bites, etc.) et demander à Claude de filtrer selon les critères :
- Buzz anglophone < 3 semaines
- Use case applicable à fondateur/freelance FR
- Testable en < 1h
- Avis tranché possible (positif OU négatif)

### Pré-qualification d'un outil
Donner le nom d'un outil → Claude répond : "Est-ce que ça vaut la peine de passer 45 min à le tester ?"

### Structurer le test
Avant de tester, Claude fournit un protocole : quoi taper, quel cas d'usage simuler, quel résultat capturer.

### Rédaction du contenu
Après le test, donner les notes brutes (ce qui a été fait, obtenu, ressenti) → Claude produit :
- Script du carrousel slide par slide
- Script du Reel avec hook en 3 secondes
- Caption Instagram
- Verdict en 3 mots

## Limites de Claude pour la veille
- Ne peut pas accéder à ProductHunt en direct (site bloque le scraping — 403)
- Peut faire des recherches web (WebSearch) pour trouver les lancements récents, sans upvotes en temps réel
- Meilleure option : copier-coller le digest email (30 sec) → filtrage immédiat
